# Slack投稿メーカー

作業内容や調査結果のメモを「結論 → 詳細 → お願い」の順番で、Slackにそのまま貼れる投稿文にします。
AIや外部サービスは使わず、テンプレートとルールだけで動きます（入力内容は外部に送られません）。

## 使い方

1. `index.html` をブラウザで開く
2. 3つを入力する
   - 投稿の目的（共有／判断のお願い／次の動きの確認）
   - ひとことで言うと（結論を1行で）
   - 詳しいメモ（箇条書きでも文章でもOK）
3. 「コピー」を押して、Slackに貼り付ける

## 整え方のルール

- 行頭の `-` `*` `・` `1.` などを取り除き、`•` の箇条書きにそろえる
- 行頭に字下げがある行は、一段下げた箇条書き `◦` にする
- 改行のない文章は「。」で区切って箇条書きにする
- 目的によって見出しの【】と「お願い」の文を変える

## 抜け漏れチェック

| チェック | 条件 |
|---|---|
| 結論が空 | 「ひとことで言うと」が未入力 |
| 結論が長い | 40文字を超える |
| 詳細が空／多すぎる | 0行、または10行を超える |
| 期限がない | 「判断のお願い」で、期限を表す言葉（まで・今週・10/15 など）がない |
| 宛先がない | 「判断のお願い」「確認」で `@` がない |
| あいまいな言葉 | なるはや・いい感じ・例の件 など |
| 全体が長い | 600文字を超える |

しきい値や言葉のリストは `index.html` の `<script>` の先頭で変更できます。
